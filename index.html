Which platform for Molly’s website?

A recommendation for Molly’s Market from Odd+Even (design). Compare Squarespace, Framer, and a custom stack — design limits, who can edit what, and how stable Molly’s brand stays after launch. Online ordering stays on ChowNow + Toast either way.

Odd+Even suggestion
Custom stack

Best if Molly’s wants its brand look locked in and a content editor built for the market (hours, FAQ, catering, seasonal pages) without the team being able to break the design. Framer is the main alternative when a design-tool CMS is preferred over a tailored editor. Squarespace is the simplest path if Molly’s prioritizes easy in-house edits over a fully custom brand system.

Approximate ongoing platform cost for Molly’s marketing site. Annual billing where available. Excludes one-time design/build fees and domain renewals. Vendor pricing can change.

Custom Framer Squarespace

Squarespace Core — $23/mo billed annually (custom code, business site).

Framer Pro + 1 editor — $30/mo site + $20/mo editor seat = $50/mo billed annually.

Custom stack — Vercel Pro ~$20/mo + GitHub Team (private) ~$4/seat/mo + Sanity Free ($0 at this scale) ≈ $24/mo. Usage overages extra if traffic spikes.

Tradeoff
